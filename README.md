# Laravel 12 CRUD User App

## Kebutuhan Sistem

- PHP >= 8.2
- Composer
- MySQL / MariaDB

## 🚀 Cara Menjalankan Aplikasi 

### 1. Clone Repository

```bash
git clone https://github.com/your-repo/laravel12-crud-modal.git
cd laravel12-crud-modal

2. instal dependency :

composer install

3. duplicate file env
cp .env.example .env

4. konfigurasi database :
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=crud_modal
DB_USERNAME=root
DB_PASSWORD=

5. migrasi database
php artisan migrate

6. jalankan aplikasi
php artisan serve

7. untuk menjalankan unit test
php artisan test
